applyMask() → {Buffer}

Applies the mask bitwise: (state & ~mask) | (gpio & mask). Unmasked bits are left unchanged. The input buffers are not mutated.

state: current GPIO state (4 bytes). gpio: new GPIO values (4 bytes). mask: mask to apply (4 bytes).

applyMaskAndUpdateGPIO(gpioBytes, maskBytes)

Applies the mask and updates the GPIO state.

For each bit:

  • if the mask bit is 1, the new value (gpioBytes) is applied;
  • if the mask bit is 0, the current GPIO state is kept. This changes only the selected GPIOs and leaves the others untouched.

The new GPIO values.
