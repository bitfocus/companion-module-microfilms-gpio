applyMaskAndUpdateGPIO(gpioBytes, maskBytes)

Fonction pour appliquer le masque et mettre à jour les GPIO

Cette fonction met à jour l'état des GPIO en appliquant un masque bit à bit. Pour chaque bit :

  • Si le bit du masque est à 1, la nouvelle valeur (gpioBytes) est appliquée.
  • Si le bit du masque est à 0, l'état actuel du GPIO est conservé. Cela permet de modifier sélectivement certains GPIO sans affecter les autres.
Parameters:
Name Type Description
gpioBytes Buffer

Les nouvelles valeurs des GPIO
maskBytes Buffer

Le masque à appliquer
